# NetFrame fonts

Self-hosted WOFF2 files used by `base/_fonts.scss`. Each font family is licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org); the full licence and copyright notice
for each family ships next to the fonts. The files were downloaded from Google Fonts (latin subset).

| File(s) | Family | Licence |
| --- | --- | --- |
| `space-grotesk-700.woff2` | Space Grotesk | `OFL-spacegrotesk.txt` |
| `jetbrains-mono-400.woff2`, `jetbrains-mono-500.woff2` | JetBrains Mono | `OFL-jetbrainsmono.txt` |
| `vt323-400.woff2` | VT323 | `OFL-vt323.txt` |
| `orbitron-400.woff2`, `orbitron-700.woff2` | Orbitron (Reserved Font Name "Orbitron") | `OFL-orbitron.txt` |
| `russo-one-400.woff2` | Russo One (Reserved Font Name "Russo") | `OFL-russoone.txt` |

`orbitron-400.woff2` is Orbitron's **variable** font (weight axis), so it serves both the
400 and 500 `@font-face` rules at their true weights.

Licence texts: `https://github.com/google/fonts/tree/main/ofl/<family>/OFL.txt`.
NetFrame's own code is GPL-3.0-only; the fonts are not covered by the GPL.
