# Tooltip

CSS-only tooltips triggered on hover or `:focus-visible`. Wrap the target in `.nf-tooltip-wrap` and place `.nf-tooltip` as a sibling inside it.

## On any element

The wrapper is `display: inline-flex` so it works on any inline element — buttons, icons, links, badges:

```html
<span class="nf-tooltip-wrap">
  <span class="nf-badge nf-badge-error">ERR</span>
  <span class="nf-tooltip">AUTHENTICATION_FAILED</span>
</span>
```

## Touch and keyboard

Tooltips are CSS-only: they show on hover and on `:focus-within`, so the trigger **must be focusable** (a button, a link, or an element with `tabindex="0"`). Plain text never shows one, and a tap on a non-focusable element does nothing. Keep essential information out of tooltips: on touch devices they appear only after a tap focuses the trigger.

Long text wraps at about 18rem and is never wider than the screen. CSS cannot detect viewport edges, so a tooltip on a control hugging the left or right edge of a narrow screen can still be partly off-screen: use `nf-tooltip-right` or `nf-tooltip-left` for edge controls, or place the tooltip with your own script if you need collision handling.

## Class reference

| Class | Description |
|---|---|
| `nf-tooltip-wrap` | `inline-flex` wrapper — triggers tooltip on hover / focus |
| `nf-tooltip` | Tooltip bubble — appears above by default |
| `nf-tooltip-bottom` | Positions below the target |
| `nf-tooltip-left` | Positions left of the target |
| `nf-tooltip-right` | Positions right of the target |
