# Drawer

Fixed slide-in panels. Toggle with the `.nf-open` class and a backdrop overlay.

## Structure

The drawer is composed of an overlay and a panel. The panel contains a header, body, and footer:

## Sides

Add `.nf-drawer-left` or `.nf-drawer-right` to control which edge the panel slides in from.

| Class | Edge | Open transform |
|---|---|---|
| `nf-drawer-left` | Left | `translateX(-100%)` → `translateX(0)` |
| `nf-drawer-right` | Right | `translateX(100%)` → `translateX(0)` |

## JavaScript

```js
const overlay = document.getElementById('drawer-overlay');
const drawer  = document.getElementById('my-drawer');
const trigger = document.getElementById('open-drawer');
const close   = drawer.querySelector('[aria-label="Close drawer"]');
const FOCUSABLE = 'a[href], button:not([disabled]), input:not([disabled]), select:not([disabled]), textarea:not([disabled]), [tabindex]:not([tabindex="-1"])';
let isOpen = false;

// Everything else under <body> becomes inert while the drawer is open.
const page = () => overlay.parentElement.querySelectorAll(':scope > :not(#drawer-overlay):not(#my-drawer)');

function setOpen(open, { moveFocus = true } = {}) {
  if (open === isOpen && moveFocus) return;
  isOpen = open;
  drawer.classList.toggle('nf-open', open);
  overlay.classList.toggle('nf-hidden', !open);
  drawer.setAttribute('aria-hidden', String(!open));
  // The closed panel sits off-screen but is still focusable unless inert.
  drawer.inert = !open;
  page().forEach((el) => (el.inert = open));
  if (!moveFocus) return;
  if (open) (drawer.querySelector(FOCUSABLE) ?? drawer).focus();
  else trigger.focus();
}

setOpen(drawer.classList.contains('nf-open'), { moveFocus: false });

trigger.addEventListener('click', () => setOpen(true));
close.addEventListener('click', () => setOpen(false));
drawer.querySelectorAll('.nf-drawer-footer button').forEach((b) => b.addEventListener('click', () => setOpen(false)));
overlay.addEventListener('click', () => setOpen(false));
document.addEventListener('keydown', (e) => {
  if (!isOpen) return;
  if (e.key === 'Escape') setOpen(false);
  if (e.key === 'Tab') {
    // Wrap focus inside the drawer.
    const items = [...drawer.querySelectorAll(FOCUSABLE)];
    const first = items[0], last = items[items.length - 1];
    if (e.shiftKey && document.activeElement === first) { e.preventDefault(); last.focus(); }
    else if (!e.shiftKey && document.activeElement === last) { e.preventDefault(); first.focus(); }
  }
});
```

Place the overlay and drawer as direct children of `<body>` so the `inert` step covers the rest of the page. Without `inert` support in your target browsers, add your own focus containment.

## Class reference

| Class | Description |
|---|---|
| `nf-drawer-overlay` | Fixed backdrop — hide with `nf-hidden` or `aria-hidden="true"` |
| `nf-drawer` | Fixed panel — slides in when `.nf-open` is added |
| `nf-drawer-left` | Left edge, primary right border |
| `nf-drawer-right` | Right edge, primary left border |
| `nf-open` | Reveals the drawer — `transform: translateX(0)` |
| `nf-drawer-sm` | 14rem width |
| `nf-drawer-lg` | 28rem width |
| `nf-drawer-xl` | 36rem width |
| `nf-drawer-header` | Top section with title and close button |
| `nf-drawer-title` | Title text inside the header |
| `nf-drawer-body` | Scrollable content area |
| `nf-drawer-footer` | Bottom action area |
