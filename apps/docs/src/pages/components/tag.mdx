## JavaScript

NetFrame remains CSS-only. This consumer-owned controller removes a direct tag child of `data-tag-list`. If focus was in the removed tag, it moves to the next enabled close button, then the previous one, then the surviving `data-tag-fallback` link/control. Choose a logical fallback for your application. Outside focus is preserved, disabled buttons are ignored, and separate groups stay independent. The optional status region announces the remaining count without taking focus. Native `disabled` suppresses activation; `aria-disabled` alone requires the guard below.

```js
document.querySelectorAll('[data-tag-group]').forEach((group) => {
  const list = group.querySelector('[data-tag-list]');
  const fallback = group.querySelector('[data-tag-fallback]');
  const status = group.querySelector('[data-tag-status]');
  if (!list || !fallback) return;
  const buttons = () => [...list.querySelectorAll('.nf-tag-close')]
    .filter((button) => button.closest('[data-tag-group]') === group);
  buttons().forEach((button) => { button.hidden = false; });

  group.addEventListener('click', (event) => {
    const button = event.target.closest('.nf-tag-close');
    if (!button || button.closest('[data-tag-group]') !== group ||
        button.disabled || button.getAttribute('aria-disabled') === 'true') return;
    const tag = button.closest('.nf-tag');
    if (!tag || tag.parentElement !== list) return;
    const order = buttons().filter((item) => !item.disabled &&
      item.getAttribute('aria-disabled') !== 'true' && !item.hidden);
    const index = order.indexOf(button);
    if (tag.contains(document.activeElement)) {
      (order[index + 1] ?? order[index - 1] ?? fallback).focus();
    }
    tag.remove();
    if (status) status.textContent = `Tag removed. ${list.querySelectorAll('.nf-tag').length} tags remaining.`;
  });
});
```

Coarse-pointer close buttons have 44px targets; mouse sizes remain compact. Long tag labels wrap while the close control keeps its size. Removal is immediate and has no animation. Screen-reader announcements still require manual verification.

## Class reference

| Class | Description |
|---|---|
| `nf-tag` | Base chip — neutral border and background |
| `nf-tag-primary` | Primary green tint + border |
| `nf-tag-secondary` | Secondary magenta tint + border |
| `nf-tag-tertiary` | Tertiary purple tint + border |
| `nf-tag-close` | `×` button inside the tag — renders via `::before` |
