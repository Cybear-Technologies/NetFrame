# Card

Cards are surface containers. Compose them with `.nf-card-header`, `.nf-card-body`, and `.nf-card-footer`.

## Class reference

| Class | Description |
|---|---|
| `nf-card` | Base surface container |
| `nf-card-header` | Header row; holds the title and subtitle |
| `nf-card-title` | Card title text |
| `nf-card-subtitle` | Muted secondary line in the header |
| `nf-card-body` | Main content area |
| `nf-card-footer` | Footer row for actions |
| `nf-card-elevated` | Brighter surface with an offset shadow |
| `nf-card-primary` | Primary (green) accent border |
| `nf-card-secondary` | Secondary (pink) accent border |
| `nf-card-inset` | Lowest, recessed surface |
| `nf-card-interactive` | Hover and focus states for a clickable card |
