## Usage

Append toasts into a fixed `.nf-toast-region` live region (present in the page before the first toast, so screen readers pick up insertions), then remove them after a timeout:

```html
<div class="nf-toast-region nf-toast-top-right" id="toast-region" aria-live="polite"></div>
```

```js
function showToast({ title, message, type = 'info', duration = 4000 }) {
  const region = document.getElementById('toast-region');
  const toast = document.createElement('div');
  toast.className = `nf-toast nf-toast-${type}`;
  // Errors interrupt; everything else waits for the polite region.
  if (type === 'error') toast.setAttribute('role', 'alert');

  // Build with textContent, never innerHTML: titles and messages often
  // contain user or server data.
  const content = document.createElement('div');
  content.className = 'nf-toast-content';
  const heading = document.createElement('div');
  heading.className = 'nf-toast-title';
  heading.textContent = title;
  const body = document.createElement('div');
  body.className = 'nf-toast-message';
  body.textContent = message;
  content.append(heading, body);

  const close = document.createElement('button');
  close.type = 'button';
  close.className = 'nf-toast-close';
  close.setAttribute('aria-label', 'Dismiss');
  close.textContent = '✕';
  toast.append(content, close);

  let timer;
  let removed = false;
  const remove = () => {
    if (removed) return;
    removed = true;
    toast.remove();
  };
  const dismiss = () => {
    clearTimeout(timer);
    toast.classList.add('nf-toast-dismissing');
    toast.addEventListener('animationend', remove, { once: true });
    setTimeout(remove, 1000); // fallback if animations are disabled
  };
  const start = () => { clearTimeout(timer); timer = setTimeout(dismiss, duration); };
  const pause = () => clearTimeout(timer);

  // Let people stop the timer while reading or interacting (WCAG 2.2.1).
  toast.addEventListener('mouseenter', pause);
  toast.addEventListener('mouseleave', start);
  toast.addEventListener('focusin', pause);
  toast.addEventListener('focusout', start);
  close.addEventListener('click', dismiss);

  region.appendChild(toast);
  start();
  return toast;
}
```

## Small screens

A toast is never wider than the screen minus its margins, and long words break instead of widening it. Regions respect `env(safe-area-inset-*)` (add `viewport-fit=cover` to your viewport meta). The dismiss button is a 44px target on touch devices.

## Region positions

| Class | Position |
|---|---|
| `nf-toast-top-right` | Top-right (default) |
| `nf-toast-top-left` | Top-left |
| `nf-toast-bottom-right` | Bottom-right |
| `nf-toast-bottom-left` | Bottom-left |

## Class reference

| Class | Description |
|---|---|
| `nf-toast-region` | Fixed container — stacks toasts vertically |
| `nf-toast` | Individual notification |
| `nf-toast-success` | Primary green left border |
| `nf-toast-error` | Error red left border |
| `nf-toast-warning` | Secondary magenta left border |
| `nf-toast-info` | Tertiary purple left border |
| `nf-toast-dismissing` | Triggers the slide-out exit animation |
| `nf-toast-content` | Flex column wrapper for title + message |
| `nf-toast-title` | Label-font heading |
| `nf-toast-message` | Body text |
| `nf-toast-close` | Dismiss button |
| `nf-toast-top-left` | Region position: top left |
| `nf-toast-top-right` | Region position: top right |
| `nf-toast-bottom-left` | Region position: bottom left |
| `nf-toast-bottom-right` | Region position: bottom right |
| `nf-toast-icon` | Icon slot at the start of a toast |
