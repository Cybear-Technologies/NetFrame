## JavaScript

Every demo above supports header sorting with a mouse, touch, Enter or Space.
NetFrame supplies the styles; this optional controller sorts rows and updates
`aria-sort`. Numeric values (including ms, %, MB and PIDs) sort numerically;
missing values stay last. Sorting does not change the underlying dataset.

<ExampleBehavior component="table" />

```js
document.querySelectorAll('.nf-table').forEach((table) => {
  const headers = [...table.querySelectorAll('thead th')];
  const body = table.querySelector('tbody');
  if (!body) return;
  const collator = new Intl.Collator(undefined, { numeric: true, sensitivity: 'base' });
  const value = (row, column) => row.cells[column].textContent.trim();
  const missing = (text) => text === '' || text === '—';
  const numeric = (text) => /^-?\d+(?:\.\d+)?(?:ms|%|MB)?$/i.test(text);
  headers.forEach((header, column) => {
    const button = header.querySelector('.nf-table-sort');
    if (!button) return;
    button.addEventListener('click', () => {
      const direction = header.getAttribute('aria-sort') === 'ascending' ? -1 : 1;
      const rows = [...body.rows].sort((a, b) => {
        const x = value(a, column);
        const y = value(b, column);
        if (missing(x) || missing(y)) return Number(missing(x)) - Number(missing(y));
        const order = numeric(x) && numeric(y)
          ? parseFloat(x) - parseFloat(y)
          : collator.compare(x, y);
        return order * direction;
      });
      headers.forEach((other) => other.removeAttribute('aria-sort'));
      header.setAttribute('aria-sort', direction === 1 ? 'ascending' : 'descending');
      body.append(...rows);
    });
  });
});
```

## Class reference

| Class | Description |
|---|---|
| `nf-table-wrap` | Overflow wrapper — apply to a `<div>` around the table |
| `nf-table` | Table element — full width, collapsed borders |
| `nf-table-sort` | Header button — optional sorting controller uses `aria-sort` on its `<th>` |
| `nf-table-striped` | Alternates even row background |
| `nf-table-row-active` | Green left border accent — selected row |
| `nf-table-row-danger` | Error left border accent — critical row |
