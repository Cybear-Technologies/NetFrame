## Class reference

| Class | Description |
|---|---|
| `nf-flex-center` | `display: flex; align-items: center; justify-content: center` |
| `nf-truncate` | Single-line truncation with ellipsis |
| `nf-uppercase` | `text-transform: uppercase` |
| `nf-tracking-display` | `letter-spacing: 0.05em` |
| `nf-text-primary` | Color: `--nf-color-primary` |
| `nf-text-secondary` | Color: `--nf-color-secondary` |
| `nf-text-tertiary` | Color: `--nf-color-tertiary` |
| `nf-text-muted` | Color: `--nf-color-text-muted` |
| `nf-text-subtle` | Color: `--nf-color-text-subtle` |
| `nf-font-display` | Font: Space Grotesk |
| `nf-font-body` | Font: JetBrains Mono |
| `nf-font-label` | Font: VT323 |
| `nf-border-primary` | Border: `--nf-color-primary` |
| `nf-border-secondary` | Border: `--nf-color-secondary` |
| `nf-border-tertiary` | Border: `--nf-color-tertiary` |
| `nf-hidden` | `display: none !important`; also hides dropdown, modal and drawer panels |
| `nf-sr-only` | Visually hidden but available to assistive technology |
| `nf-flex` | `display: flex` |
| `nf-flex-col` | Flex column |
| `nf-flex-between` | Flex row, centred, space between |
| `nf-flex-wrap` | `flex-wrap: wrap` |
| `nf-flex-1` | `flex: 1` |
| `nf-flex-shrink-0` | `flex-shrink: 0` |
| `nf-line-clamp-2` | Clamp text to 2 lines |
| `nf-line-clamp-3` | Clamp text to 3 lines |
| `nf-text-error` | Text colour: `--nf-color-error` |
| `nf-bg-surface` | Background: `--nf-color-surface` |
| `nf-bg-surface-low` | Background: `--nf-color-surface-low` |
| `nf-bg-surface-high` | Background: `--nf-color-surface-high` |
| `nf-border` | Border: `--nf-color-border` |
| `nf-border-l-primary` | 4px left border, primary |
| `nf-border-l-secondary` | 4px left border, secondary |
| `nf-border-t-primary` | 4px top border, primary |
